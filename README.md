# gfdash-llm-compare

[gfdash](https://github.com/air-terminal/gfdash)（ゴルフ練習場向けダッシュボード）の AI レポートを、ローカルの LLM ごとに比べた記録です。
同じ入力（公開デモの合成データ）に対してモデルだけを変えてレポートを作り、品質・処理速度・プロンプトと前後の処理を改良できる余地を調べています。

| 回 | 内容 | モデル |
|---|---|---|
| [2026-11](2026-11/) | 見通し・営業レビュー（多段／1回）。計150件。thinking OFF の追加の測定、所見の解析の比較あり | gemma-4 12B / 26B-A4B / 31B（QAT）、Qwen3.6 27B、Qwen3.8 27B、llm-jp-4.1 33B thinking、gpt-oss-20b（llama.cpp）、Qwen3.8-Flash-Next IQ3_S / Q4_K_XL（Strata） |

各回のフォルダに、条件・結果の文書（README）、1件ずつの記録、プロンプトの全文、検査のスクリプトがあります。

## データについて

- 来場者数・天候・所見は、gfdash の公開デモ用に作った合成データです。実在の施設の数値ではありません
- レポートの本文は、各モデルが生成したものをそのまま載せています（誤りを含みます。誤りの一覧は各回の `results/reading_notes.md`）
- 1条件あたりの生成は1〜2回で、seed も固定していません。モデルの優劣ではなく、この作業・この構成での傾向として読んでください
